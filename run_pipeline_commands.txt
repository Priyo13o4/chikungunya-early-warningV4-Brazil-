Here is your quick `tmux` cheat sheet, perfect for copying and pasting into your project notes!

### The Essential `tmux` Commands

* **Start a new session:**
```bash
tmux

```


*(Optional: Name it so it's easier to find by using `tmux new -s training`)*
* **Enable Mouse Scrolling (The "Scroll Wheel" trick):**
1. Press **`Ctrl + b`** and release both keys.
2. Type **`:`** (Shift + semicolon). A yellow prompt will appear at the very bottom.
3. Type `set -g mouse on` and press Enter.
*(Now you can use your Mac's trackpad/scroll wheel to scroll up through all your training logs!)*


* **Detach (Leave it running safely in the background):**
1. Press **`Ctrl + b`** and release both keys.
2. Press **`d`**
*(You will see `[detached]` and can safely close VS Code or sleep your Mac).*


* **Reattach (Come back to your running code):**
```bash
tmux attach

```


*(If you named it earlier, use `tmux attach -t training`)*
* **List your running sessions (If you forget what's running):**
```bash
tmux ls

```


* **Kill the session entirely:**
When your script is completely finished and you want to close the `tmux` window for good, just type `exit` in the terminal and press Enter.
