4. Enable Mouse Scrolling (Optional but highly recommended)
If you want to use your Mac's trackpad to scroll up and read old print statements inside the tmux window:

Press Ctrl + b

Release both keys.

Type : (Shift + semicolon). A yellow prompt will appear at the very bottom.

Type set -g mouse on and press Enter
